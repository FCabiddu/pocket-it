# Mappa degli spec E2E del giro di fine onda: la legge scripts/e2e-scelta.sh.
# Modello del flusso lite (lite/templates/spec-per-cartella.txt); la tiene l'architect.
#
# @spec <glob...>       dove stanno gli spec: «tutti» sono questi (default e2e/**/*.spec.ts)
# @test <regex>         un file di test che combacia non porta nulla
# =GRUPPO spec...       un gruppo di spec (una superficie, una rotta)
# <prefisso> <voci...>  un file cambiato il cui percorso inizia con <prefisso> porta le sue voci;
#                       una voce è un GRUPPO, uno spec, «tutti» o «nessuno». Contano tutte le righe che combaciano.
# Uno spec cambiato porta sé stesso. Un file che non combacia con nessuna riga porta «tutti»:
# ogni cartella dell'app deve avere la sua riga, se no ogni onda lancia la suite intera.
# Uno spec nuovo o una superficie nuova aggiunge qui la sua riga nella stessa PR.
# Si controlla con `bash scripts/e2e-scelta.sh --verifica`.

@spec e2e/**/*.spec.ts
@test (/__tests__/|\.test\.[jt]sx?$)

# Gruppi (esempio)
=HOME e2e/home.spec.ts
