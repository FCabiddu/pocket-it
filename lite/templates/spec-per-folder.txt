# Map of the E2E specs for the end-of-wave run: scripts/e2e-select.sh reads it.
# Template of the lite flow (lite/templates/spec-per-folder.txt); the architect maintains it.
#
# @spec <glob...>       where the specs live: «all» means these (default e2e/**/*.spec.ts)
# @test <regex>         a test file that matches brings nothing
# =GROUP spec...        a group of specs (one surface, one route)
# <prefix> <entries...> a changed file whose path starts with <prefix> brings its entries;
#                       an entry is a GROUP, a spec, «all» or «none». Every matching line counts.
# A changed spec brings itself. A file that matches no line brings «all»:
# every folder of the app must have its line, otherwise every wave runs the whole suite.
# A new spec or a new surface adds its line here in the same PR.
# Checked with `bash scripts/e2e-select.sh --check`.

@spec e2e/**/*.spec.ts
@test (/__tests__/|\.test\.[jt]sx?$)

# Groups (example)
=HOME e2e/home.spec.ts
