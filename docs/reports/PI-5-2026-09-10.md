# PI-5 — Raise the handoff fact cap from 30 to 100

## What changed and why
`bin/handoff.sh` previously refused a new fact at 30/30 (PI-2 behaviour, kept as-is), but a real
project hit the ceiling in a single wave, and one agent worked around the refusal by deleting an
older fact itself — exactly the call the cap is meant to reserve for the retro. Raised the cap to
100 and made it a single `CAP=100` variable read by every place that used to hard-code `30`: the
`fact` python subprocess (now takes CAP as argv), the `show` cap marker, and the fatti-section
HTML comment written on each successful `fact` add. Added an unconditional `sed` normalisation
step, run on every subcommand (`log`/`fact`/`show`), that rewrites a stale `max N righe:` comment
left over from an older handoff file to the current `CAP` — so no project handoff file contradicts
the enforced cap even if it predates this change.

## Tests <-> acceptance criteria
- AC1 (fact reaching the cap lands, exit 0, warns) -> `AC1 — fact reaching the cap lands with exit 0`, `AC1 — stderr warns the cap is reached`, `AC1 — the fact reaching the cap is actually in the file`
- AC2 (fact past the cap refused, file unchanged, exit 3, exact line) -> `AC2 — refused fact exits 3`, `AC2 — file unchanged when refused`, `AC2 — file still has 100 facts, not 101`, `AC2 — the new fact is not in the file`, `AC2 — exact stderr line`
- AC3 (`show` marker at/below cap) -> `AC3 — show ends with the cap marker`, `AC3 — below cap, show has no cap marker`
- AC4 (stale comment normalised on any run) -> `AC4 — stale 'max 30 righe' comment is normalised to the new cap`, `AC4 — pre-existing fact survives the normalisation`
- AC5 (test file green, no special-casing) -> all 17 assertions in `bin/handoff.test.sh` green; `CAP=100` is the only place the number is defined in the script
- AC6 (`CLAUDE.md`) -> `handoff.sh` row, History log row and Learning loop row updated to `100`
- `log` behaviour unaffected by the facts cap -> two pre-existing assertions kept (`log still exits 0 …`, `log still caps at 40 lines`)
