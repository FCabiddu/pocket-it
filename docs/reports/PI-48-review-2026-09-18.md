## Notes

- **N1** — "every difference from `main` is an addition" is one string off: `src_anchors`' `MUT_WHY` went
  from `…in the captured bin/doctor.sh:` to `…in the captured source:`. A modification, necessary for a
  shared file, harmless (`doctor.test.sh` greps only the `^anchor found N times, not 1` prefix).
- **N2** — `raw_writers()` (AC4's static side) recognises a redirection of `"$SCRIPT"`/`"$SCRIPT_SRC"` and
  `cp`/`cat` of them. A copy written as `python3 - "$SCRIPT_SRC" "$out" <<'EOF'` — the idiom
  `doctor.test.sh`'s own `external_mutation` uses — matches neither alternative. The check states its
  threat model ("cooperative … the idiom all four blocks used before PI-48"), so this is a note outside
  that model, not a finding; sides 1 and 2 still catch such a copy on disk.
- **N3** — AC1 rests on two layers, not one. `run_mutant()` guarantees an unapproved copy is never
  *executed*. It does not by itself guarantee the failure *name*: a block that dropped its `if`/`else`
  would get an empty `$OUT` and its downstream `has` rows would fail under their own names. All four live
  blocks carry the pair, so AC1 holds.
