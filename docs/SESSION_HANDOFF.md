- cleanup-merged.sh: ancestry or topology never proves a branch has work of its own — a fresh branch is an ancestor of its base, and the base it came from may since be merged and deleted. 'Commits of its own' is read from the branch's own reflog (a commit/cherry-pick/revert/am/merge-commit entry, or a rebase replaying one, still in the tip's history); fresh (only 'branch: Created from') and no-reflog branches are kept; 'Branch: copied'/'Branch: renamed' entries restart the reading (git branch -c/-m carry another ref's reflog, commit entries included). - guard.sh push guard is NOT a security boundary: it stops a COOPERATIVE agent pushing to the base branch by MISTAKE in a normal shell form; deliberate evasions (eval, bash -c, env -i, wrappers, quoted/escaped git, on-the-fly aliases, push-affecting config, send-pack) are left to server-side branch protection, and the threat model is at the top of guard.sh. - A pixel check for clipped text must neutralise the whole class of clippers, not an example list: every overflow value (hidden/clip/auto+fixed height, -webkit-line-clamp), clip-path and clip: rect() on positioned elements, contain: paint|content|strict, content-visibility, mask/mask-image/-webkit-mask-*/mask-border, overflow-clip-margin — measured on 5 of them (clip:rect, contain:paint, contain:strict, content-visibility:hidden, mask-image): the shipped screenshot and one with only overflow:visible+clip-path:none forced show 0 differing pixels while the full class reset finds thousands, so a partial neutralisation declares a clipped text clean.
- A clip-detection check must never use any threshold/tolerance, and never a metrics-box comparison (canvas.measureText().actualBoundingBox*, getBoundingClientRect, scrollHeight) even as a fallback — measured: Rockwell line-height 1 clips gjpqy by 89px in the screenshot but measures ink at 94.97px against a 96px box (under the box, so the metrics check calls it clean). The single correct method: diff the whole text region (not just the element's own box) between as-shipped and whole-class-neutralised, with background/border-color/box-shadow forced transparent in BOTH shots (else a decorative background under a clip-path becomes a false positive). **Scope both the class-reset and the transparency to `*, *::before, *::after` across the WHOLE PAGE, plus hide non-text media (`img,video,canvas,svg,iframe{visibility:hidden}`), never just the checked element and its ancestors** — a clip can sit on the element itself or on a descendant (e.g. a masking wrapper inside a headline) and an ancestors-only reset misses both (measured: 0 diff on element-itself and descendant clips with the narrow scope, nonzero with the page-wide one). A layout property (line-to-line pitch, hidden-at-rest) needs its own proof, never this pixel-diff procedure reused: neutralising the clipper to check "is it hidden" always shows a difference since hiding IS the clipper's job — use a `* { color: transparent }` control shot for hidden-at-rest, and an `offsetTop` delta for pitch.
